Spički 3D — интерактивный 3D-зал (three.js r170, без сборки).
index.html + app.css — интерфейс; main.js — камера, клики, панели, звук; world.js — сцена; tex.js — текстуры на canvas.
Папка самодостаточная (свои шрифты, звуки, фото, three.js в vendor/) — её можно отдавать и с поддомена 3d.spickibg.com.
Параметры для ссылок: ?lang=ru|sr|en, ?view=hookah|bar|tv|secret|photos, ?open=<предмет>, ?skip — без приветствия.
Звуки кальяна — Freesound, CC0 (см. ../sfx/CREDITS.txt). three.js — MIT (vendor/THREE-LICENSE).
