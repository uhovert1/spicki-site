# Раздел «Новости кальянного мира»

Цель раздела: каждый день одна полезная новость из мира кальянов, чтобы сайт spickibg.com находился в поиске по запросам
«кальяны Белград», «кальянная Белград», «кальянная Сербия», «nargile Beograd», «nargila bar Beograd», «hookah Belgrade», «shisha Belgrade».

Каждая новость существует на трёх языках и на трёх отдельных адресах:
`/news/<slug>.html` (RU), `/news/sr/<slug>.html` (SR, латиница), `/news/en/<slug>.html` (EN).

## Как добавить новость

1. Создать файл `news/data/ГГГГ-ММ-ДД-<slug>.json` (формат ниже).
2. Запустить из корня репозитория: `python3 tools/news_build.py`.
   Скрипт проверит файл и пересоберёт страницы новостей, списки `/news/`, блок последних новостей на главной и `sitemap.xml`.
   Если он напечатал «ОШИБКА», исправить файл и запустить снова.
3. Закоммитить и запушить в `main` (GitHub Pages опубликует сайт сам за 1–2 минуты).

Руками сгенерированные HTML-файлы в `news/` не править: их перезаписывает скрипт.

## Формат файла

```json
{
  "date": "2026-11-13",
  "slug": "es-nalog-na-kalyannyj-tabak",
  "image": "img/g/10-l.webp",
  "image_pos": "50% 30%",
  "sources": [{"title": "Издание: заголовок (дата)", "url": "https://..."}],
  "ru": {
    "tag": "Законы и рынок",
    "title": "до 110 символов, с ключевыми словами",
    "description": "70–200 символов, для поисковой выдачи",
    "lead": "1–2 предложения под заголовком",
    "image_alt": "описание картинки",
    "body": "<h2>…</h2><p>…</p>",
    "faq": [["Вопрос?", "Ответ."]]
  },
  "sr": { … то же на сербском (латиница) … },
  "en": { … то же на английском … }
}
```

- `slug` — латиница, цифры и дефисы; один и тот же для всех трёх языков; не повторять уже существующие.
- `body` — только теги h2, h3, p, ul, ol, li, strong, em, a, blockquote, br, table. Без картинок, скриптов и стилей.
  Ссылки — только `https://…` или `../…`.
- `faq` — 2–4 вопроса, которые реально задают в поиске; ответы короткие и точные.
- `sources` — все источники, на которые опирается текст (минимум два независимых, если это возможно).

## Редакционные правила

- Только реальные новости за последние 7 дней, проверенные по источникам. Ничего не выдумывать: ни цифр, ни цитат, ни дат.
  Если факт есть только в одном источнике, писать «по данным <издание>».
- Текст свой, не пересказ одного источника близко к тексту. Цитаты — максимум одна короткая (до 15 слов) в кавычках с указанием автора.
- Каждая новость объясняет, что она значит для Сербии / Белграда и для гостей кальянных. Не придумывать связь, которой нет:
  если для Сербии ничего не меняется, так и написать.
- Про Spički — только проверенные факты: Mačvanska 10, Врачар, Белград, примерно 5 минут пешком от Храма Святого Саввы;
  ежедневно с 12:00 (вс–чт до 00:00, пт–сб до 01:00); кальяны готовит кальянный мастер (табак и крепость под компанию,
  угли меняют вовремя по таймерам); своя кухня, бар, вино, коктейли, настольные игры, бизнес-ланч из трёх блюд в будни;
  два VIP-стола с PS5, закрытая Secret Room с пятью игровыми ПК (бронируется целиком, до 5 гостей); только 18+;
  оплата наличными и картой; онлайн-бронь на book.spickibg.com подтверждается сразу; меню на Qastio; доставка Wolt.
  Цифры: средний чек 1 500–4 000 RSD на человека (по данным Google), бизнес-ланч 1 300 RSD. Других цен и акций не упоминать.
- Не рекламировать конкретные марки табака и не призывать курить: это новости, а не реклама. Без медицинских утверждений
  о «безопасности» кальяна. Аудитория — только совершеннолетние.
- Тон спокойный, информативный. Объём основного текста — примерно 350–600 слов на язык.
- SEO: в заголовке и первом абзаце естественно использовать «кальян/кальянный» (SR: «nargila/nargile», EN: «hookah/shisha»)
  и, где уместно, «Белград/Сербия» (Beograd/Srbija, Belgrade/Serbia). Не перебарщивать с ключевыми словами.
- Темы: законы и налоги (Сербия, ЕС, регион), рынок и компании, выставки и события, новые устройства (электронные кальяны,
  угли, чаши), культура и история кальяна, тренды кальянных. Не повторять тему, которая уже была на сайте за последние 14 дней.

## Главные страницы на трёх языках

`tools/news_build.py` после сборки новостей вызывает `tools/home_build.py`: он пересобирает `sr/index.html` и `en/index.html` из `index.html` (переводы берутся из I18N). Эти два файла руками не правят. Для сборки нужен `node`.
